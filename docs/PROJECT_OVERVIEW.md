# OmniBrain

## Project Description

OmniBrain is an enterprise-grade multi-modal Retrieval-Augmented Generation (RAG) system that enables users to query information from PDFs, images, tables, and SQL databases using Large Language Models (LLMs) and AI agents.

## Objectives

- Upload documents
- Extract text and images
- Store embeddings
- Search using vector databases
- Generate AI-powered responses
- Support SQL querying
- Support image understanding

## Expected Outcome

Users can ask natural language questions and receive accurate answers based on uploaded data.
