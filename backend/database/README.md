# Database

This folder contains the database-related files for the OmniBrain project.

## Contents

- `schema.sql` – Defines the database schema.
- `models.py` – SQLAlchemy ORM models (to be added in Day 2).
- `db.py` – Database connection configuration (to be added in Day 2).

## Tables

### documents
Stores uploaded document information.

### chunks
Stores extracted text chunks from uploaded documents.

### chat_history
Stores user questions and AI-generated responses.
